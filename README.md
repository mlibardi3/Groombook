# GroomBook v0.9 AI

This version combines the AI scanner with shop scheduling configuration.

New:
- Add/edit/delete groomers
- Per-groomer full-groom capacity and bath capacity
- Per-groomer workdays
- Preferred drop-off style
- Max noon-pickup dogs
- Preferred recurring interval
- Free-text scheduling preferences/restrictions
- Mark groomer days off
- Conflict Center for dogs already booked on newly unavailable dates
- Same-day transfer suggestions to another groomer when available
- Requested groomer's next-opening suggestion
- For recurring clients, option to shift future dates
- Manual booking
- Recurring booking
- Existing v0.8 AI card/schedule scanning and separate camera/gallery buttons

Important:
- Data is still saved in browser localStorage for the prototype.
- Amanda's seeded values are placeholders; edit them to the real capacity.
- Do not bulk-import the whole shop until we move to a real database.
