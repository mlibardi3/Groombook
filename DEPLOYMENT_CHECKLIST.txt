GroomBook v0.7 — deployment checklist

1. Create/choose a Node-compatible hosting provider.
2. Upload this project (or connect a Git repository).
3. Add OPENAI_API_KEY as a PRIVATE server environment variable.
4. Optional: OPENAI_MODEL=gpt-5-mini
5. Deploy.
6. Open /api/health and verify aiConfigured=true.
7. Open the site on the phone.
8. Test ONE client card.
9. Carefully compare every AI-extracted field to the physical card.
10. Test ONE schedule page.
11. Do not discard the paper schedule/cards during this prototype phase.

Never put the API key into public/index.html.
